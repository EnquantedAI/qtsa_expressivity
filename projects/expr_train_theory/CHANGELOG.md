# Changelog

Added a NumPy implementation of the pure-state QFIM together with analytical checks for simple one- and two-parameter states. A small PennyLane adapter returns the full state of the shared circuit so the same code can be used there.

Added CFIM/QFIM examples while reviewing the Effective Dimension implementation. They cover a measurement that reaches the QFIM, a phase parameter invisible in the computational basis and the behaviour near zero probabilities.

Added a standalone Krylov prototype with Lanczos, Arnoldi, projected evolution and basic spreading measures. The follow-up scripts compare several Hamiltonian/state pairs, perturb the inputs, compare Hamiltonian and unitary-step constructions, and look at state spans generated by layered circuits.

The latest scripts repeat the circuit checks over random initialisations and entangling topologies, calculate simple correlations between diagnostics and flag quantities that are constant or nearly redundant in the sampled data.
