# Changelog

Added a NumPy implementation of the pure-state QFIM together with analytical checks for simple one- and two-parameter states. A small PennyLane adapter returns the full state of the shared circuit so the same code can be used there.

Added CFIM/QFIM examples while reviewing the Effective Dimension implementation. They cover a measurement that reaches the QFIM, a phase parameter invisible in the computational basis and the behaviour near zero probabilities.

Added a standalone Krylov prototype with Lanczos, Arnoldi, projected evolution and basic spreading measures. The follow-up scripts compare several Hamiltonian/state pairs, perturb the inputs, compare Hamiltonian and unitary-step constructions, and look at state spans generated by layered circuits.

The latest scripts repeat the circuit checks over random initialisations and entangling topologies, calculate simple correlations between diagnostics and flag quantities that are constant or nearly redundant in the sampled data.

Added a first reference implementation of trajectory participation dimension. It works directly with a sequence of state snapshots, computes the SVD/Gram spectrum and checks simple boundary cases such as identical, orthogonal and duplicated states.

Added a small layered-state snapshot generator for the trajectory participation work. It records the encoded state and the state after each variational layer, with optional data reuploading, and runs the current $d_{TP}$ calculation on those trajectories.

Added a trajectory adapter for the current shared QNN. It records the state after encoding and after every full layer while keeping the current input trimming, feature maps, entangling pattern and optional reuploading. The final state can also be checked against the outputs of the simple and batched shared models.

Added a small shared-QNN sweep for trajectory participation. It varies layers, qubits, feature maps and reuploading, while keeping the input window length as a separate setting, and saves raw and grouped results for later comparison.

Added a small directional check for trajectory participation. It records how $d_{TP}$ changes with circuit depth and compares matched trajectories with and without data reuploading, without assuming that either effect has to be strictly monotone.

Added a sampling-sensitivity check for trajectory participation. It compares equal-weight and weighted versions of the metric, including a simple duplication example and resampling of the same one-qubit path.

Added a perturbation check for trajectory participation. It compares direct snapshot noise with small changes of the variational parameters and records how much $d_{TP}$ moves together with the average state infidelity.

Added a small calibration helper for trajectory participation. It reports the raw value against the numerical rank and the maximum available trajectory dimension, together with entropy effective dimension and stable rank. The boundary tests include identical, orthogonal and duplicated directions.

Added a small cross-metric check for trajectory participation, QFIM and computational-basis CFIM on the same toy models. It is mainly useful for seeing where the metrics disagree because they probe different objects, rather than treating disagreement as an implementation error.

Added a small shared-QNN cross-metric sweep. It evaluates trajectory participation, QFIM and computational-basis CFIM on the same sampled circuits and saves per-architecture summaries plus simple correlations.
Added a small dTP/QNTK cross-check with an explicit finite-difference Jacobian reference. It includes analytical tests and a toy case showing that a parameter can change the state trajectory while being invisible to a chosen model output.


Added a small architecture sweep comparing normalized trajectory participation with QNTK diagnostics on the same toy layered circuits. It varies depth, qubit count, entangling gates and reuploading and saves the per-configuration summaries and simple cross-metric correlations.

Added a few analytic boundary checks for trajectory participation and QNTK. They cover a collapsed trajectory, an orthogonal trajectory, a constant-output kernel, a linear model with a known kernel and a model with redundant parameter directions.

Added a small validation runner for trajectory participation. It collects the analytic boundary cases, duplicate/sampling checks, perturbation checks and depth/reuploading diagnostics into one report. Only cases with a known analytical answer are marked pass/fail; the architecture trends are kept as descriptive diagnostics.

Added a compact reference table for dTP, QFIM, computational-basis CFIM and QNTK. The examples are chosen so that redundant directions and phase-only directions show up differently across the metrics, which makes the distinction between state-space and output/parameter-space diagnostics easier to check.

Added a small agreement report on top of the metric profile. It labels which of dTP, QFIM, CFIM and QNTK respond in each reference case and records the rank gaps, mainly to make state-space vs output-space disagreements easier to spot.

Added a small bootstrap check for the cross-metric comparisons. It reports uncertainty intervals for the dTP/QNTK correlations so the exploratory sweeps are not interpreted from a single point estimate alone.

Added an overlap-based view of trajectory participation. It verifies that $d_{TP}$ is the inverse purity of the trajectory mixture and, for equal weights, the inverse normalized first state frame potential of the trajectory snapshots.

Added a spectral interpretation of trajectory participation. It checks explicitly that $d_{TP}=\exp(H_2)$ and compares it with the Shannon effective dimension, stable rank and numerical rank from the same trajectory spectrum.

Added a hard-subspace comparison for trajectory participation. A small modified Gram-Schmidt routine is checked against the SVD numerical rank and shows explicitly that trajectories with the same linear span can still have different $d_{TP}$ because their spectral weight is distributed differently.

Added a direct Gram-matrix backend for trajectory participation. It computes the same spectrum, rank and $d_{TP}$ as the state-matrix SVD route, while also allowing the metric to be evaluated from precomputed snapshot overlaps only.

Added Fubini--Study arc-length weighting for trajectory participation. It gives a phase-invariant way to reduce the effect of uneven snapshot density while keeping genuine changes of the circuit trajectory separate from the sampling convention.

Added a matched architecture comparison for equal-weight and Fubini--Study-weighted trajectory participation. It records both versions together with projective path length so depth and reuploading trends can be checked for snapshot-density effects.

Added a matched entanglement-graph check for trajectory participation. It keeps inputs and variational parameters fixed while changing the CNOT topology and records simple graph descriptors next to $d_{TP}$ and trajectory rank.

Added a matched cross-metric extension to the entanglement-topology study. It reuses the same input sets and parameter draws across graph topologies and records trajectory participation, pure-state QFIM diagnostics and a reference QNTK based on the final-state $\langle Z_0\rangle$ output.

Added matched topology deltas relative to the no-entanglement baseline and a small descriptor-association report for dTP, QFIM and QNTK. The analysis stays descriptive because the reference topology set is too small to support a predictive claim. Also clarified that the computational CFIM identifies the generic output variable $y$ with the computational-basis outcome $z$, so it uses $p_\theta(z\mid x)$.

Added a matched entanglement-topology comparison between equal-weight and Fubini--Study-weighted trajectory participation. It reports topology shifts relative to the same no-entanglement parameter draw, together with projective path length, so topology effects can be checked for sensitivity to the snapshot weighting convention.

Added a comprehensive matched entanglement-topology runner. It collects graph descriptors, equal-weight and Fubini--Study-weighted trajectory participation, projective path length, QFIM and the reference QNTK in one experiment and one topology-level summary, with matched shifts relative to the no-entanglement baseline.

Added a width/depth stability sweep for the comprehensive matched topology experiment. It reports raw and trajectory-ceiling-normalized equal/FS $d_{TP}$ shifts together with QFIM relative-rank and QNTK effective-rank shifts, and summarizes whether the sign of each topology effect persists across the sampled circuit sizes. The stability report is kept descriptive rather than treated as a significance or monotonicity test.

Added a multi-seed uncertainty check for matched topology shifts across the width/depth sweep. Independent repeat seeds are bootstrapped at the repeat level for normalized equal/FS $d_{TP}$, QFIM relative rank and QNTK effective rank, with intervals kept separate from the existing descriptive sign-stability diagnostic.

Added a conservative robust-effect summary for the multi-seed topology study. Configuration-level bootstrap intervals are classified as stable positive, stable negative or unresolved, and the topology/metric aggregate is called stable only when every sampled width/depth configuration is resolved in the same direction.

Added a frozen `topology_robust_v1` reproducible-study preset for the entanglement-topology work. One runner now executes the matched multi-seed width/depth pipeline and saves the raw table, bootstrap uncertainty, CI stability, robust classifications and an exact parameter/seed manifest in one output directory.

Finalized the public interface and documentation for the entanglement-topology study. The package now exposes only the frozen reproducible-study surface at top level, the official runner supports `--help`, `--show-preset` and an optional output directory, and the README clearly separates release reproduction from focused diagnostic runners.

Finalized the graph-topology release surface and audited the reproducible-study contract. Custom programmatic presets now propagate their declared baseline topology through the full matched width/depth and uncertainty pipeline; the frozen `topology_robust_v1` release preset remains unchanged and continues to use `none`.
