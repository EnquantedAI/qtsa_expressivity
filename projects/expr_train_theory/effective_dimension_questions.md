# Effective Dimension: points to settle later

These do not block the current small tests, but they should be fixed before a common benchmark:

- use the full computational-basis distribution or a distribution tied to the forecasting output;
- choose the input set used for Fisher averaging;
- agree on parameter ranges and the local sampling radius;
- record the probability cutoff and numerical rank threshold;
- compare CFIM and QFIM on a small shared set of circuits.
