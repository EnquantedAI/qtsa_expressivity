# Krylov notes

For an operator $A$ and starting vector $v$,

$$
\mathcal K_m(A,v)=\mathrm{span}\{v,Av,\ldots,A^{m-1}v\}.
$$

The current code covers:

- Lanczos for Hermitian operators;
- Arnoldi for general operators;
- state spreading in the Krylov basis;
- Hamiltonian and unitary-step constructions;
- spans generated by intermediate circuit states.

The main modelling choice is still the operator. For the shared QNN possible choices include an effective Hamiltonian, a repeated circuit unitary or the span of states visited by the layers. The experiments keep these cases separate instead of calling all of them the same metric.
