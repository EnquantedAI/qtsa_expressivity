# Notes

For a fixed circuit architecture I use

$$
|\psi(x,\theta)\rangle = U(x,\theta)|0\rangle^{\otimes n},
$$

where `x` is the input and `theta` contains trainable parameters.

The quantities used in the project describe different things:

- QFIM describes the local geometry of the state family;
- classical FIM depends on the chosen measurement probabilities and is used in Effective Dimension;
- Krylov quantities depend on the operator and the starting state;
- gradient statistics concern trainability;
- MSE and $R^2$ describe forecasting performance.

For a normalized pure state the QFIM convention in the code is

$$
F^Q_{ij}=4\,\mathrm{Re}\left(
\langle \partial_i\psi|\partial_j\psi\rangle
-\langle \partial_i\psi|\psi\rangle
\langle \psi|\partial_j\psi\rangle
\right).
$$

The current reference implementation uses central finite differences. It is slow, but easy to check on small examples. The tests cover a single rotation, redundant parameters, independent rotations and a global phase.

For Krylov calculations I keep the operator and starting state explicit. The experiments currently compare Hamiltonian Krylov spaces, unitary-step spaces and spans generated by layered circuits. These are related constructions, but they should not be treated as identical without checking the assumptions.
